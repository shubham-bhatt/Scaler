# Scaler Interview Prep Notes

Personal study vault for interview prep: **DSA, LLD, HLD, and SQL** (coding + design rounds). Plain Markdown so it renders anywhere.

📚 **Start here → [notes/INDEX.md](notes/INDEX.md)** — the single source of truth for how this vault is organized, what's written, and what's still a stub.

## Structure at a glance

- **Bucket** = subject folder (`DSA`, `LLD`, `HLD`, `SQL`)
- **Subbucket** = one `.md` file grouping a handful of related topics
- **Topic** = a section inside that file
- Each subject also has a consolidated **`cheatsheet.md`** for last-minute revision
- Original lecture PDFs/source material live alongside the notes they were built from

## How to use it

- Skimming before an interview? Go straight to a subject's `cheatsheet.md`.
- Digging into a specific topic? Open the relevant subbucket file linked from [notes/INDEX.md](notes/INDEX.md).
- Adding new content? Follow the `/notes` skill workflow — it reads `notes/INDEX.md` to route new material to the right file and keeps the index current.
